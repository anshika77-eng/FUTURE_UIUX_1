# Home Service Website UI/UX Redesign

## Overview
This project focuses on redesigning a local home service business website with a strong emphasis on lead generation and conversion optimization.

## Pages Designed
- Homepage
- Service Page
- Contact / Lead Page

## Tools Used
- Lovable (AI-assisted no-code UI builder)

## UX Explanation
A conversion-first approach was followed, prioritizing clear CTAs, trust-building elements, and a frictionless contact flow.
Primary CTA placement above-the-fold ensures immediate user action, while a secondary call option supports urgent service needs.
Trust indicators are included early to reduce hesitation, and the layout follows a mobile-first approach.
